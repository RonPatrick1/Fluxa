# Fluxa

Fluxa is a media-library project currently represented by the web prototype
and GTK experiments at the repository root.

## Related workspace tools

The following self-contained projects are intentionally stored alongside
Fluxa even though they are unrelated to the media-library application:

- `bose-flex-tools/` contains Linux command-line tools and research notes for
  the family's Bose SoundLink speakers.
- `bose-battery-voice/` contains the offline Android, iOS, and Ubuntu battery
  announcement helper.

Each Bose project has its own README with usage, safety, and build details.
