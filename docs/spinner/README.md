# Loading spinner

Requirements for Fluxa's video-loading spinner. The HUD spinner is the sole
loading indicator; the former comparison spinner has been removed.

## Reference

- Copy the HUD look from
  [this Shutterstock clip](https://www.shutterstock.com/video/clip-1073254547-hud-circle-head-up-display---hi-tech-futuristic).
- No numbers, words, or round dots.
- No dashes, tick marks, or triangles.

## Look

- Keep Fluxa's green-ish theme.
- Concentric rings of different widths.
- Mostly boxes on those rings.
- Overlay several parts; they do not all have to share the same width or
  transparency.
- Build it from stacked overlayed pieces, some transparent.
- Box spacing should be irregular, not evenly marched around the circle.
- Some boxes filled, some transparent / unfilled.
- Centered correctly.
- Rings should feel like a concentric ring-puzzle lock, not one even track
  with dividing lines.
- Widths should vary enough that some rings overlap.
- No clear divider lines between the already varied-width rings.
- Some rings were too wide later; keep widths from getting huge.
- A few different-width boxes should sit side by side (about 3 or 4), or
  collide sometimes.

## Motion

- Smooth, not choppy.
- Irregular motion per ring, not all locked together.
- Rings should smoothly reverse direction.
- Some rings stop and fade out quickly.
- Some spin very quickly, then go backwards and stop.
- Fast rings still have to stay smooth; speed should not turn into stutter.

## Glow

- Glow like the HUD example.
- Glow the ring-boxes, parts, and lines — not the whole spinner as one blob.
- Most parts glow; some parts do not glow at all.

## "T" marks

- Add irregular T-shaped lines like the example.
- Those lines move the same way the rings do (independent irregular motion).
- T's are not attached to boxes.
- T's live on their own rings, some transparent, some not; some glowing, some
  not.
- They can start/rotate with some boxes so they do not look glued on, but they
  must not look attached.
- T's overlap the boxes; they are not outside the box rings.
- No T-only ring on the outside.
